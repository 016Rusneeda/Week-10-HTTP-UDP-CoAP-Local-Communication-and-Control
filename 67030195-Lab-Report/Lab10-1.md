#### ผลการทดสอบ Reconfigure ระบบบิลด์

ทดสอบรันคำสั่ง Reconfigure เพื่อให้ระบบดาวน์โหลดคอมโพเนนต์และสร้างบิลด์ไฟล์
```powershell
idf.py reconfigure
```

เมื่อปรากฏข้อความ `-- Configuring done` และ `-- Generating done` แสดงว่าโครงสร้างโปรเจกต์พร้อมสำหรับการเขียนโค้ดในกิจกรรมถัดไป

## 4. บันทึกผลการทดลองและคำถามท้ายการทดลอง
1. นำผลการรัน `curl -i` (โหมด verbose เพื่อดู HTTP Response Header) มาแปะในรายงาน พร้อมวิเคราะห์ว่า HTTP Header มีขนาดกี่ไบต์ และข้อมูล JSON มีขนาดกี่ไบต์

  **ตอบ** ผลการรัน `curl -i`
```
HTTP/1.1 200 OK
Content-Type: application/json
Content-Length: 46

{"pot_raw":1250,"free_heap":213848,"led":false}
```
HTTP Header มีขนาด 71 ไบต์ และข้อมูล JSON มีขนาด 46 ไบต์


2. หากในเครือข่ายมีคอมพิวเตอร์ที่ไม่รองรับ mDNS หรือปิดกั้นพอร์ต UDP 5353 จะเกิดผลกระทบอย่างไร และแก้ไขได้อย่างไร?

   **ตอบ**
  - ผลกระทบคือจะไม่สามารถแปลงชื่อ esp32-node.local เป็น IP ได้ ทำให้หาบอร์ดไม่เจอ   
  - วิธีแก้ เรียกใช้งานผ่านหมายเลข IP โดยตรง หรือเปลี่ยน Wi-Fi บน Windows เป็น "Private Network" เพื่อปลดบล็อก Firewall
   
3. เหตุใดจึงต้องเรียกคำสั่ง `cJSON_Delete(root)` และ `cJSON_free(resp)` เสมอหลังจากประมวลผลเสร็จสิ้น?
   
   **ตอบ** เพื่อคืนพื้นที่หน่วยความจำ (RAM) ให้กับระบบ หากไม่ทำจะเกิดปัญหา Memory Leak ทำให้ RAM เต็มและบอร์ดค้างหรือรีสตาร์ท
